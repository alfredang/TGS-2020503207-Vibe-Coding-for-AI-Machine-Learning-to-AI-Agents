# Hands-On Labs — AI Vibe Coding for Multi-Agents System

**Course code:** TGS-2020503207  |  **Duration:** 2 days  |  **Provider:** Tertiary Infotech Academy Pte Ltd (UEN: 201200696W)

Eleven hands-on labs covering the five topics of the course, from a hand-rolled agent loop through to a hierarchical multi-agent system orchestrating MCP tools.

## Learning outcomes

- **LO1:** Explain the components of a modern AI agent — skills, memory, tools and the Model Context Protocol (MCP) — and the progression from single-agent to multi-agent collaboration.
- **LO2:** Apply a structured vibe coding workflow with context engineering to specify, generate and verify agent code reliably.
- **LO3:** Build a collaborative multi-agent system with the OpenAI Agents SDK using structured outputs, tool calling and supervisor routing, and deploy it with Streamlit.
- **LO4:** Build a collaborative multi-agent system with the Google Gemini Agent SDK and deploy it with Streamlit.
- **LO5:** Orchestrate tools through MCP and design hierarchical sub-agent architectures for delegated, specialised work.

## Setup

### 1. Python environment

Python 3.11 or newer is required.

```bash
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

Or with [uv](https://docs.astral.sh/uv/):

```bash
uv venv && source .venv/bin/activate
uv pip install -r requirements.txt
```

### 2. API keys

Create a `.env` file in your working folder. **Never commit this file** — it is already listed in `.gitignore`.

```bash
# Labs 01-02, 05-07, 11
OPENAI_API_KEY=sk-...

# Labs 08-09
GOOGLE_API_KEY=...
GOOGLE_GENAI_USE_VERTEXAI=FALSE
```

- OpenAI keys: <https://platform.openai.com/api-keys>
- Gemini keys: <https://aistudio.google.com/apikey>

Every lab reads keys via `os.getenv` / `python-dotenv`. No key should ever appear in source. Verify before committing:

```bash
git grep -nE "sk-[A-Za-z0-9]{20}"   # must return nothing
git status --short                  # .env must not appear
```

### 3. Vibe coding tool (Labs 03-04, 10)

Install at least one:

- **Claude Code** — `npm install -g @anthropic-ai/claude-code`
- **Gemini CLI** — `npm install -g @google/gemini-cli`
- **Cursor** — <https://cursor.com/>

## Dependencies

Installed by `requirements.txt`:

| Package | Used in | Purpose |
|---|---|---|
| `openai` | Labs 01-02 | Raw Chat Completions API and hand-rolled tool-calling loop |
| `openai-agents` | Labs 05-07, 11 | OpenAI Agents SDK (imported as `agents`) |
| `pydantic` | Labs 05-06, 11 | Structured outputs and validated agent results |
| `google-adk` | Labs 08-09 | Google Agent Development Kit for Gemini agents |
| `streamlit` | Labs 07, 09 | Web UI deployment |
| `mcp[cli]` | Labs 10-11 | Model Context Protocol server and inspector |
| `python-dotenv` | All | Loads API keys from `.env` |
| `requests` | Labs 05, 10 | HTTP calls from function tools |

> **Version note.** Lab 10 uses `FastMCP` from the `mcp` 1.x line. In `mcp` 2.0.0 the class was renamed to `MCPServer` and `FastMCP` was removed, so `requirements.txt` pins `mcp[cli]>=1.9,<2`. Lab 10 documents the 2.0 equivalent.
